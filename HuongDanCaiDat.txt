Hướng Dẫn Cài Đặt Các Công Cụ Hỗ Trợ cho Chương Trình:

- cài OpenAi API key: Nếu muốn sử dụng OpenAi API key cho giai đoạn SUMMARIZE và EXPLAIN, tạo 1 file ".env" sau đó điền "OPENAI_API_KEY=sk-proj-AUWEYxT72....". Do không thể công khai API key lên github, nên bạn phải tự chuẩn bị API key

- Cài Ollama để dùng DeepSeek-r1-14B: 
    1. Truy cập https://ollama.com/download/linux
    2. Cài đặt: 
		- Linux: "curl -fsSL https://ollama.com/install.sh | sh". 
		- Windows: "https://ollama.com/download/OllamaSetup.exe"
    3. Tải DeepSeek-r1 14B về: "ollama pull deepseek-r1:14b"
    4. Sau khi tải xong, có thể kiểm tra bằng: "ollama run deepseek-r1:14b"
