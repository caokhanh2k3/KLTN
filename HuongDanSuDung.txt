
Chạy Chương trình:
- Để tiếp kiệm thời gian chạy, dữ liệu được tạo ra sau khi chạy 1 giai đoạn có thể được dùng chung giữa các file thực hiện giai đoạn sau. 
- Nên những file thụt lề sâu hơn phải chạy sau. 
- Các file cùng cấp (cùng độ dài thụt lề) có thể chạy không cần theo trình tự.
- Các file khác thư mục với nhau cũng có thể chạy không cần theo trình tự.
- khi mở 1 file .ipynb đọc các tiêu đề ở markdown chạy lần lượt từ trên xuống dưới. 
- Nếu RAM GPU không đủ lớn thì đừng chọn "Run all", điều đó có thể bị hết RAM khi chạy Out of memory do cị rò rỉ bộ nhớ ở những bước cell code trước. Nếu bị "Out of memory" hãy thực hiện "restart kernel", Bời vì tôi đã chia thành nhiều bước nhỏ khi thực hiện, mỗi bước sẽ lưu lại kết quả bằng các file csv, json hoặc lưu model. Nếu đã hoàn thành bước nào rồi thì có thể bỏ qua, chỉ run những cell code có liên quan đến bước kế tiếp
