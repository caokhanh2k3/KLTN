
Chạy Chương trình:
- Để tiếp kiệm thời gian chạy, dữ liệu được tạo ra sau khi chạy 1 giai đoạn có thể được dùng chung giữa các file thực hiện giai đoạn sau. 
- Nên những file thụt lề sâu hơn phải chạy sau. 
- Các file cùng cấp (cùng độ dài thụt lề) có thể chạy không cần theo trình tự.
- Các file khác thư mục với nhau cũng có thể chạy không cần theo trình tự.
- khi mở 1 file .ipynb đọc các tiêu đề ở markdown chạy lần lượt từ trên xuống dưới. 
- Đừng chọn "Run all". Nếu RAM GPU không đủ lớn thì có thể bị hết RAM khi chạy. Lúc này cần restart kernel, kiểm tra những cell code nào cần thiết thì chạy lại, những cell code nào đã chạy xong và lưu được kết quả rồi thì hãy bỏ qua.
